# 内脏毁伤与反馈机制 — 规划（参考 Ketchup and Doll，不抄资源）

参考：https://17han5.itch.io/ketchup-and-doll-sim（公开页面 / 开发日志 / 玩家描述）。只借鉴**架构分层**，不使用其资源、网格、贴图或代码。

Ketchup and Doll 是偏解剖物理的沙盒：枪伤会留下入射 / 出射创口，弹道在体内可能转向或被组织减速；按命中部位区分皮肤、骨骼、内脏；有出血与组织破坏；钝器先出现淤伤再渗血；肢体可在极端情况下分离；透视 / X 光用来看清内部损伤；支持多目标、多次命中。玩家反馈还提到：脂肪厚度影响穿透、弹道空洞（permanent cavity）与暂时空腔、头部与内脏的手感要不同、毁伤开关要可调。这些作为**后续目标**，本轮只做可用的第一层 + 干净钩子。

## 本轮已落地的第一层（见 `docs/weapons.md`）
- 物理弹壳（按武器对型号、10 秒回收、数量上限、对象池）。
- 真实弹头飞行（速度 / 重力 / 阻力、扫掠防穿透、命中世界留下弹痕）。
- 击中人体：入射创口、弹道通道、能量足够时出射；皮肤与脏器沿弹道受冲击（击腹波 + 通道形变）；肠道 / 子宫被命中时变红、局部撕裂形变；分身同样生效。
- 狙击精英式弹道特写：设置开关默认开、概率默认 20%；弹道将穿过肠道或子宫时有机会触发慢动作 + 透视跟随。

## 后续架构（不要把逻辑写死在武器脚本里）

建议保持四层，全部数据驱动，武器只提供「能量 / 口径 / 速度 / 截面」：

1. **弹道层**（已有雏形：`ballistics.gd`）
   - 继续完善：穿过不同介质（空气 / 皮肤 / 软组织 / 骨）的减速与偏转；霰弹逐粒独立；保留 `shot_fired` / `hit` / 身体命中信号。
   - 记录完整路径（入口、体内段、出口、残留能量），供毁伤层和特写镜头回放。

2. **穿透与空腔层**（本轮只做简单能量 vs 体厚，后续细化）
   - 临时空腔（temporary cavity）：高速弹（步枪）在软组织里向外挤推，是冲击波 / 脏器抖动的来源，随后回弹。
   - 永久空腔（permanent cavity）：弹头直接撕开的通道，留下创口和通道网格 / 着色器痕迹。
   - 口径、速度、弹头形状（圆头 9mm vs 尖头 5.56 vs 霰弹丸）决定空腔半径和是否出射。步枪更容易贯穿；手枪看体厚；霰弹丸近距离冲击大、很快失速，通常留在体内。
   - 后续可加：骨的破碎与转向、不同器官密度、肥胖层加厚（玩家建议过这类设定）。

3. **器官状态层**（每个 OrganRig / 分身一份，互不覆盖）
   - 每颗器官（肠道、子宫，以及后续肝、胃、膀胱、卵巢等）一份状态：完好 → 挫伤 / 充血 → 穿孔 → 撕裂 → 毁损。
   - 状态由「该器官上的永久空腔体积、命中次数、残留能量」推进，可逆的只有最轻的挫伤。
   - 视觉：已有 `tools.damage[12]` 发红 + 本轮弹道通道；后续再加局部网格撕裂、出血点、组织外翻、蠕动减弱或痉挛。
   - 反馈：已有击腹冲击波和肠蠕动兴奋；后续按器官加更明确的触感（子宫被击中的局部收缩、肠道的拖拽式位移），不要只用屏幕特效。
   - 出血：点状渗血（低能）→ 沿通道流出（穿孔）→ 积在腹腔。与现有刺刀伤口贴花共用预算，注意数量上限。

4. **命中部位与多次命中**
   - 用腹部局部坐标 + 器官 AABB / 网格距离判定部位（不要只靠角色圆柱体）。
   - 多次命中叠加（通道相邻则合并加宽），分身与本体各算各的。
   - 克隆、工具互动、透视窗口必须继续可叠加：毁伤是 OrganRig 上的额外状态，不能打断拖拽 / 拳交 / 刺刀 / 肚脐。

## 钩子（本轮已预留，后续不要再拆一次）
- `Ballistics.hit` / `body_hit` / `organ_path`：命中世界、命中身体、弹道穿过的器官列表。
- `OrganRig.ballistic_query` / `apply_ballistic_hit`：只查询或查询并施加第一层效果。
- `OrganRig` 上的弹道通道列表、`tools.damage` / `tools.wounds`：后续永久空腔和器官状态写在同一处。
- `GameSettings`：特写开关与概率已持久化；后续毁伤强度、是否显示创口、是否出血都可以进同一份 `user://settings.cfg`。

## 明确不做（除非以后单独开一轮）
- 不抄 Ketchup and Doll 的模型、贴图、血液粒子或实现。
- 本轮不做断肢、骨骼粉碎、独立血液流体求解、角色死亡 / 倒地。
- 本轮不做完整的每器官状态机和持久形变网格；着色器通道和发红是可替换的占位表现。
