# 阴道互动模式

这是后续核心功能的底子。模式、镜头和工具栏先搭好，插入物继续走已有的 `VulvaInserter` / `VulvaParams`（见 `docs/vulva_module.md`）。

## 文件

| 路径 | 作用 |
|---|---|
| `scripts/interact/vagina_mode.gd` | 模式进入/退出、镜头预设、当前工具。Player 用 `get_vagina_mode()`。 |
| `scripts/interact/vagina_tool.gd` | 工具资源：id、显示名、图标、设置面板种类、插入物脚本。 |
| `scripts/interact/vagina_tool_registry.gd` | 数据工具表。新工具 `register()` 即可，不必改 HUD 布局逻辑。 |

## 怎么进出

检查床上（包括观察模式）可进。电脑按 **Y**，或点「阴道互动」。与手术模式互斥：进一个会退出另一个。退出后回到进入前的观察/控制视角。

**站姿进入（T-15）**：观察模式下不在检查床上时，按 **Y** 或点「阴道互动」会以当前站姿原地进入（`VaginaMode.enter_standing()`），不再上床。进入期间 `player.set_body_mode_hold(true)` 把角色钉在原位（不倒地、不被碰撞推开），镜头相对当前阴道轴线计算：轴线接近竖直时「阴道口视角」改为从前下方约 45° 看外口，环绕仰角仍在相机限幅内。离开观察模式或进入布娃娃时自动退出；退出后松开锁定并回到观察视角。手术同理：`SurgerySystem.enter_surgery_standing()`，镜头对准腹部，切下的皮瓣落到脚下地面，取出的子宫 / 肠袢按重力挂在创口下方。

进入时镜头自动飞到外阴附近，环绕中心在下体（阴道口到宫颈的中段），而不是肚脐。

## 镜头预设

轴线取自当前蒙皮后的阴道中线（`OrganRig.vagina_canal()`：外口 → `os_center`）。

- **自由视角**：以下体为中心环绕，右键旋转、中键平移、滚轮拉近，手机划屏同样可用。
- **阴道口视角**：相机在外口外侧，前向与阴道轴线一致，看向入口里面。
- **小腹视角**：相机在小腹一侧，前向与轴线垂直，看子宫、阴道和卵巢的整体。默认打开透视，方便隔着腹壁观察。

以后若要加「侧位」「宫颈特写」，在 `VaginaMode.set_camera_preset()` 里加一个预设名即可。

## 工具栏（扩展点）

工具是资源，不是写死在手术脚本里的 `if`。注册表默认包括：

- `speculum` — 阴道扩张器（从手术栏移入，插入/开合/取出行为不变，仍由 `SpeculumTool` 执行）
- `ball_rod` — 长柄金属球（镀铬圆杆+末端圆球，直径滑条同时改外形和碰撞）
- `reserved_2` / `reserved_3` — 预留空位

加新工具：做一份 `VaginaTool`（或在 `setup_defaults()` 里 `register()`），实现 `VulvaInserter`，需要的话加 `settings_kind` 和 HUD 里对应的设置条。模式脚本不用为每个道具写特殊分支。


## 阴道扩张器

上下两瓣共享同一个扩张体积：叶片外壳加上它们之间空隙的凸包，截面是圆角矩形（stadium），不是上下两团更大的椭圆。`EnvelopeInserter`（`blade_sep>0` 时）和 `speculum_offset` 着色器同一公式。半高 = 闭合半高 + 距铰链距离 × tan(半开合角)，组织贴合此外表面。体外一侧的影响只有约 7–8 mm，被扩张的外口不会明显凸出体表。

## 长柄金属球

选中后出现在外口外侧，沿活中线对齐。电脑左键或手机拖拽移动：

- **阴道口视角**：指针射线与阴道轴线求最近点。画面中央是通道深处，往中心拖就是插入，四周是瞄准外口。
- **小腹 / 自由视角**：投到含阴道轴线、尽量侧对相机的平面上，沿可见的通道推拉。

通道用着色器扩张环（`dilate_*`，与 CPU 的 `OrganRig.canal_dilate_radius_at` 同一公式）跟着球走，球过后弹性回缩到杆径。球不在轴上时，扩张环中心跟着侧向偏移（`dilate_lat`）。宫颈是阻力闸门：阈值随球直径变高，攒够被挡住的行程后才会突然穿过（短促一震，宫颈圈先撑开再收在杆上）。进入宫腔后 `UterusCavity` 和子宫外膜按球半径撑开。往外拉同样要过宫颈。

杆在通道或宫腔里左右、前后移动时，阴道和子宫会被带着做弹性搅动（`stir_off` / `canal_stir_offset`），杆一停就回弹到当前的静止扩张形状。子宫原本是前倾弯折的；球穿过宫颈再往里推，会绕宫颈把宫体逐渐顶直（`uter_str`），让球能沿杆轴深入而不穿模；抽出后弯折恢复。脱垂触发 #1 和宫颈闸门仍然有效：脱垂已经开始时不跟球杆抢子宫姿态。

加同类道具：做 `VaginaTool`（`controller_script` + `inserter_script`），实现 `VulvaInserter`，需要的话加 `settings_kind`。不必改模式脚本的特殊分支。


### 子宫脱垂（触发 #1）

球直径 ≥ 约 23 mm、在宫腔里时用力 / 快速往外扯：宫颈卡住球，子宫被一起拖出来（脱垂 I–IV 度），松手后挂在已达到的等级。小球或轻拉照旧弹出。拉到完全脱出后再多拉，或把球缩小，球从宫颈脱出。点中体外的脱出物可以直接用手拖、甩、往回推。详见 `docs/uterine_prolapse.md`。

## 断面图

选中长柄金属球时，右上角默认打开可开关的断面图小窗（「并排」为默认，也可只看纵向或横向）。

- **纵向**：沿阴道轴线的矢状面（面内含轴线和腹侧朝向）。正交相机从体侧看，外口到子宫一整条。
- **横向**：过球心（也可改深度）、垂直于轴线的切片，看通道圆环和金属球截面。

渲染：主场景里给子宫 / 宫腔 / 阴道 / 外阴 / 金属球各做一份断面拷贝，各自用独立的材质实例（不写源网格的全局着色参数）。纵向拷贝在第 15 层、横向在第 16 层，对应相机只看自己那一层，所以横切面不会再看到矢状面切下来的皮肤。主相机（以及其它非断面相机）会清掉这两层，主视图不会被切面的白填充盖住。切面着色器从源材质拷变形参数（扩张环、搅动、子宫撑开/顶直），再加剖切面裁剪。背面顶点压到剖切面上，纵向看起来像子宫的平切实心切面。横切的阴道环仍按离轴线距离做黏膜 / 肌壁 / 脂肪 / 皮肤的漫画分层（不是独立解剖网格）。靠近切面画深色轮廓。

脱垂时断面图加入脱垂专用子宫模型，阴道显示被撑开（t68u 起无内翻、无体外套筒）；纵向视图自动框住脱出物，横切面放在外口。
