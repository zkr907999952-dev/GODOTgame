# 生命值与布娃娃

## 生命值
- 本体与每个分身各有一份独立生命值（`CharacterHealth`），默认上限 / 初始均为 **100**。打其中一方不会改另一方的血。
- 伤害由 `CombatDamage` 结算：武器基础伤害 × 部位倍率 × 距离衰减。命中走现有 `Ballistics._on_body`，不打断创口 / 脏器通道。
- 血量归零时发出 `died`，启动布娃娃。分身被击杀后不会自行复活；本体可用底端中央血条旁的「复活」把生命值重置并站起来，菜单在倒地期间仍可用。

|---|---:|---:|---|---|---|---|

部位判定：击中物理骨骼时按骨名（`C_Head_a` / 颈 / 四肢）；活着时打中站立胶囊，则按命中点最近骨骼或相对高度粗分。

## 布娃娃
- 使用官方 Godot 4 `PhysicalBoneSimulator3D` + `PhysicalBone3D`（见 [Ragdoll system](https://docs.godotengine.org/en/4.7/tutorials/physics/ragdoll_system.html)）。模型本身没有物理骨骼，运行时按蒂法骨架生成约 20 块碰撞（骨盆盒子 + 脊柱 / 胸 / 颈 / 头 / 肩 / 上臂 / 前臂 / 手 / 大腿 / 小腿 / 脚胶囊）。
- 关节：脊柱 / 肩 / 髋 / 颈 / 头为 Cone（限制摆动与扭转），肘 / 膝 / 踝为 Hinge。质量约 55kg 分配，线性阻尼 1.2、角阻尼 3.2，摩擦 0.85，无弹跳，可睡眠。
- 碰撞层 2（角色，供弹道射线命中），mask 只撞世界层 1。Jolt 的碰撞是双向 OR，因此骨骼之间不会互撞，避免折叠爆炸；与地面正常接触。
- Jolt 不支持 Cone / Hinge 关节的 softness 参数（会刷警告并忽略），因此未设置该项，只保留 span / 角度限位、bias 与 relaxation。
- 击杀瞬间沿弹方向施加冲量（略带向上分量），尸体不会无故垂直软倒。之后子弹再打中尸体，会在命中点前生成一颗短寿命高速球体（`RigidBody3D` + 连续碰撞，层 mask 只打角色层 2，不改骨骼互不碰撞的约定），用刚体撞击推动布娃娃，并保留一部分残余冲量。步枪比手枪更重，霰弹每一丸都会各自生成球体并贡献推动。骨速有上限，避免一发手枪把尸体打进地板或甩出地图。
- 活人（本体 / 分身，只要还没死）受击会做局部骨骼抖动：命中区域短暂“让一下”再回弹到走跑/待机动画，不是全身布娃娃，肢体不会一直软掉。不旋转锁骨，持枪 IK 仍在同一物理帧覆写手臂。
- 拖拽尸体：第一人称准星指到已死亡布娃娃时，准星/命中点上方出现「拖拽」切换按钮；再按一次放下。PC 按 **E** 是同一个切换（与 T 循环腹部互动模式互不影响）。距离上限是角色手臂长，超出无法开始，走太远（水平离开）会自动放下。站立时够不到地上的尸体，需要蹲下或趴下折腰才能抓住。拖拽时左手抓住准星选中的那块骨骼/命中点，持握点跟第一人称视线走，移动视角会把尸体拉起来。链接用有上限的弹簧把抓取点拉向左手（Jolt 上 PinJoint3D 连 PhysicalBone3D 会把骨头弹飞，因此不用关节）。放下后左手回到枪或空手姿势。
- 死亡后：停止 SoftLoco / 武器 IK / 注视与呼吸眨眼写骨，脏器停止蠕动但网格仍跟随骨骼，头发 Verlet 继续跟头。关掉站立 `BodyHit` / 玩家胶囊，避免挡住射线。子弹改为打在物理骨骼上。
- 尸体整局不自动删除。换地图时只清掉还活着的分身；尸体留在出生的那张地图里，地图隐藏时冻结物理，回来后再解冻。菜单「清除所有分身」仍会清掉尸体（玩家主动操作）。
- 本体死亡：切到第三人称环绕并跟随胸部骨骼，不锁菜单。不允许再切回第一人称走动。

## 生命值 UI
- 玩家：屏幕底端中央、武器信息卡下方，数字 + 动态颜色条（健康绿 → 中段黄 → 低血红）。不与摇杆重叠。血量为 0 时在血条旁显示「复活」。
- 分身及其它有生命值的目标：准星（屏幕中心射线）指到时，在目标头顶显示血条和数字；移开后约 0.7 秒淡出。不会对所有目标常驻显示。
